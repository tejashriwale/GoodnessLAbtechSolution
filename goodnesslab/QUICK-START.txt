🚀 HOW TO RUN THE WEBSITE (EASIEST METHOD)
================================================================================

1. Double-click: run-dev.bat
   (This file is in the project folder)

2. Wait for the message: "Ready in X.Xs"

3. Open your web browser and go to:
   http://localhost:3000

4. To stop: Press Ctrl+C in the command window

================================================================================

================================================================================

Before using run-dev.bat for the first time:

1. Open Command Prompt
2. Navigate to project:
   cd D:\PROJECT\GOODNESSLAB\goodnesslab

3. Install dependencies:
   npm install

4. Wait for installation to complete
5. Now you can use run-dev.bat anytime!

🆘 TROUBLESHOOTING
================================================================================

Problem: "npm is not recognized"
Solution: Install Node.js from https://nodejs.org

Problem: "Port 3000 already in use"
Solution: Close other programs using port 3000, or use:
          npm run dev -- -p 3001

Problem: Page doesn't load
Solution: 1. Check terminal for errors
          2. Restart server (Ctrl+C, then run-dev.bat again)
          3. Clear browser cache (Ctrl+Shift+R)

Problem: Changes don't appear
Solution: 1. Make sure file is saved
          2. Refresh browser
          3. Check for error messages in terminal
